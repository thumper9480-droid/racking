# روال اندروید ۳ — نسخهٔ قابل نصب برای آزمون

Android 8 به بالا. این نسخه رابط وب را به‌صورت فایل محلی داخل APK نگه می‌دارد و برای زنگ، اعلان و انتخاب/ذخیرهٔ فایل از Android استفاده می‌کند. برای اجرای رابط و خواندن اکسل اینترنت لازم نیست.

## نصب و انتقال داده

APK را روی گوشی دریافت و نصب کنید. برای انتقال اطلاعات نسخهٔ وب، از تنظیمات وب «ذخیرهٔ همهٔ اطلاعات» بگیرید و در تنظیمات اپ «بازیابی اطلاعات» را انتخاب کنید. فایل Excel فعلی هم مستقیماً قابل ورود است. اطلاعات مرورگر و اپ خودکار همگام نمی‌شوند. فایل خصوصی اکسل کاربر داخل APK نیست.

در تنظیمات اپ، «مجوز زنگ، اعلان و صفحهٔ قفل» را بزنید؛ اجازهٔ اعلان، زنگ دقیق و اعلان تمام‌صفحه را فعال کنید. بسته به نسخهٔ Android لازم است پس از هر مجوز، دوباره دکمه را بزنید. برای بیدارباش، گزینهٔ بیدارباش طبق اکسل را روشن و ذخیره کنید. در تنظیمات باتری گوشی، محدودیت فعالیت پس‌زمینهٔ روال را بردارید. پس از Force stop برنامه را دوباره باز کنید. صدای زنگ و تنظیمات مزاحم نشوید گوشی هم بر شنیدن زنگ اثر دارند.

## کار و وقفه

بخش پلتفرم یا فعالیت دیگر را شروع کنید. پایان زمان، فعالیت را دقیقاً در پایان بخش می‌بندد و تا انتخاب بعدی، زمان اضافه ثبت نمی‌کند. می‌توانید استراحت، بخش بعدی، زمان دلخواه یا پایان را انتخاب کنید. مدت استراحت از تنظیمات گوشی یا فرم کار/استراحت تعیین می‌شود.

«کار پیش آمد؛ وقفه» دلیل را ثبت می‌کند؛ زمان تماس، خانواده، استراحت و سایر گزینه‌ها جدا ثبت می‌شود. «برگشت» زمان باقی‌ماندهٔ کار قبلی را ادامه می‌دهد. فعالیت جاری در اعلان دیده می‌شود. پایان بخش و یادآوری کارها از AlarmManager و زنگ native استفاده می‌کنند. زنگ تا خاموش‌کردن ادامه دارد. در صفحهٔ قفل، تأیید زنگ شما را به انتخاب مرحله در اپ می‌برد. بیدارباش امکان تعویق پنج‌دقیقه‌ای دارد.

## ساخت و بررسی

```sh
python3 scripts/package-mobile.py
./gradlew assembleDebug lintDebug testDebugUnitTest
```

SDK 35، Java 17 به بالا و Gradle 8.11.1 لازم‌اند. scripts/cloud-build.sh مسیرهای محیط توسعهٔ این ماشین را دارد. نسخهٔ دانلود فعلی debug-signed است و برای نصب مستقیم و آزمون کاربر تهیه شده؛ برای انتشار فروشگاهی، کلید امضای انتشار اختصاصی لازم است.

آزمون منطق مشترک:

```sh
node --test desktop/tests/engine.test.cjs desktop/tests/excel.test.cjs desktop/tests/redesign.test.cjs
```

آزمون رابط بسته‌بندی‌شده با Playwright و mock پل اندروید، با سرور assets در پورت 4174:

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory app/src/main/assets
node app/tests/mobile-browser.cjs
```

این آزمون ورود Excel، برنامه‌ریزی اعلان، وقفه و ادامه، پایان بخش، استراحت، بازگشایی پس از موعد، بیدارباش و پشتیبان را بررسی می‌کند. برای اجرای آزمون ورودی، مسیر فایل خصوصی از MOBILE_TEST_XLSX گرفته می‌شود.

ساخت، lint، هفت آزمون Java و آزمون رابط بسته‌بندی‌شده موفق بوده‌اند. دستگاه یا شبیه‌ساز Android در محیط موجود نبود؛ صدای واقعی، قفل صفحه، Doze، مجوزها، انتخابگر فایل native و رفتار سازندگان گوشی باید روی دستگاه بررسی شوند. موفقیت آزمون مرورگر به معنی آزمون این بخش‌های سیستم Android نیست.
