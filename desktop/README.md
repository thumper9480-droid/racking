# روال وب ۳.۰

نسخهٔ وب برای استفاده روی کامپیوتر و گوشی، با ذخیرهٔ اطلاعات در همان مرورگر. نسخهٔ Android پوشهٔ app جداست؛ این تغییرات به APK قبلی اضافه نشده‌اند.

## اجرا و آزمون

از ریشهٔ مخزن:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory desktop
```

فایل‌های index.html، engine.js، excel.js، views.js، app.js، style.css، icon.svg، raval-template.xlsx و پوشهٔ vendor اجزای انتشار هستند. بستهٔ ExcelJS محلی بارگذاری می‌شود و فایل اکسل به سرور فرستاده نمی‌شود. برای اعلان‌ها سایت HTTPS را باز کنید.

```sh
node --test desktop/tests/engine.test.cjs desktop/tests/excel.test.cjs desktop/tests/redesign.test.cjs
node desktop/tests/browser.cjs
node desktop/tests/excel-browser.cjs
node desktop/tests/grace-browser.cjs
```

آزمون‌های مرورگر به Playwright، Chromium در /usr/bin/chromium و سرور محلی نیاز دارند. برای آزمون فایل خصوصی، مسیرش را در TRACK_XLSX تعیین کنید؛ فایل کاربر جزو انتشار نیست.

## تغییرات نسخهٔ ۳

- امروز با ردیف‌های فعالیت، بخش‌های زمانی قابل تیک، پنل تمرکز، توقف و ادامه، تعویض سریع فعالیت و ثبت گذشته.
- جدول برنامهٔ هفتگی و ماهانه، با شماره و تاریخ شمسی، بیدارباش، بخش‌های هر گروه و جمع هدف و زمان واقعی. بخش تکمیل‌شده سبز می‌شود؛ تیک دستی زمان واقعی ایجاد نمی‌کند.
- برنامه فقط از تاریخ‌های ورودی ساخته می‌شود؛ برنامهٔ پیش‌فرض هفتگی حذف شده و تاریخ بدون ورودی هدف فرضی نمی‌گیرد. برنامه‌های اختصاصی قبلی خودکار حذف نمی‌شوند.
- فایل اکسل پیش از ورود پیش‌نمایش دارد. گزینهٔ «مرجع کامل برنامه» تاریخ‌های قدیمی غایب از فایل جدید را حذف می‌کند و زمان‌های واقعی، تیک‌ها و کارهای پروژه را حفظ می‌کند. برای رفع برنامه‌های قدیمی خارج از فایل جدید از این گزینه استفاده کنید.
- هر گروه خالی یا ستاره‌دار، ارفاقی همان فعالیت است. جبران، تیک روز اصلی را می‌زند و زمان واقعی در روز انجام می‌ماند. عدد ۱ همچنان یک دقیقه است؛ نشانهٔ ارفاقی، خانهٔ خالی یا ستاره است.
- ساخت و ویرایش کار همراه تاریخ و ساعت؛ مرور پایان روز با انجام شد، انتقال، بایگانی و ثبت درصد پیشرفت جزئی و باقی‌مانده، همراه سابقهٔ تغییرات. زمان مرور پیش‌فرض ۲۱:۰۰ و قابل تنظیم است. کار عقب‌افتاده هنگام بازکردن بعدی برنامه هم برای مرور می‌آید.
- گزارش روز، هفته، ماه و سال با کارت‌های شاخص، نمودار هدف و زمان واقعی، نمودار حلقه‌ای سهم فعالیت‌ها و نمایش کارهای باقی‌مانده؛ وضعیت بدون داده به‌صراحت نمایش داده می‌شود.
- تنظیمات با یک فایل کامل JSON برای همهٔ برنامه‌ها، پروژه‌ها، سابقه، تیک‌ها، زمان‌ها و تنظیمات؛ CSVها زیر «خروجی برای تحلیل». زمان جاری تا لحظهٔ تهیهٔ پشتیبان ثبت می‌شود و تایمر پس از بازیابی خودکار اجرا نمی‌شود.
- تنها دکمهٔ دریافت اکسل «دانلود قالب خام برنامه و کارها» است. قالب عمومی شبیه TRACK، فشرده و بدون دادهٔ شخصی است؛ شیت کارها و گروه‌ها هم دارد.

## داده و انتشار

کلید raval-desktop-v1 حفظ شده؛ پشتیبان‌های مدل نسخهٔ ۱ و ۲ پذیرفته می‌شوند و مدل نسخهٔ ۲ با revision=3 استفاده می‌شود. زمان‌های واقعی و برنامه‌های اختصاصی حفظ می‌شوند. هیچ همگام‌سازی خودکار میان مرورگرها وجود ندارد؛ انتقال با پشتیبان JSON است.

GitHub Pages از ریشهٔ شاخهٔ gh-pages منتشر می‌شود. فایل خصوصی TRACK.xlsx نباید منتشر شود. تغییر نسخهٔ فایل‌ها در index.html باعث تازه‌شدن منابع می‌شود.

یادآوری وب به بازبودن صفحه و فعال‌بودن مرورگر نیاز دارد؛ هنگام بسته‌بودن صفحه یا خواب دستگاه، زنگ مداوم شبیه ساعت اندروید تضمین نمی‌شود.
